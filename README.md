# World Population Prediction Using Linear Regression

## Project Overview

This project uses historical world population data to analyze population trends and predict future population values using a Linear Regression model.

The project was developed using Python, Pandas, Seaborn, Matplotlib, and Scikit-learn.

## Objectives

- Explore historical world population data.
- Analyze population trends through data visualization.
- Build a Linear Regression model.
- Predict future world population based on historical trends.
- Save the trained machine learning model using Pickle.

## Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn
- Pickle
- Jupyter Notebook

## Methodology

1. Data Loading and Exploration
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Train-Test Split (80:20)
6. Linear Regression Model Training
7. Population Prediction
8. Model Serialization using Pickle

## Machine Learning Model

**Algorithm:** Linear Regression

**Input Feature:** Year

**Target Variable:** World Population

The model learns the relationship between historical years and world population values to estimate population for a given year.

## Prediction Example

The model can predict world population for a specified year, including 2030.


## How to Run

1. Clone this repository.
2. Install the required libraries.
3. Open `main.ipynb` using Jupyter Notebook or visual studio code.
4. Run the notebook cells sequentially.
